# Mohamed Abdelazim Islamic App | تطبيق محمد عبد العظيم الإسلامي

تطبيق إسلامي متكامل لأوقات الصلاة والتنبيهات، صدقة جارية على روح **محمد عبد العظيم**.

## 🌟 المميزات (Features)
* **أوقات الصلاة:** حساب دقيق لمواقيت الصلاة بناءً على الموقع الجغرافي.
* **التنبيهات (Notifications):** خدمة تنبيهات تعمل في الخلفية للأذان والتذكير.
* **الأذكار:** قسم خاص للأذكار اليومية.
* **واجهة مستخدم بسيطة:** تصميم سهل الاستخدام يتناسب مع كافة الفئات.

## 🛠 التقنيات المستخدمة (Tech Stack)
* **Language:** Java / XML
* **Platform:** Android Studio
* **Build System:** Gradle
